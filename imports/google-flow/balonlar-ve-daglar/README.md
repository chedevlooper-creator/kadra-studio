# Balonlar ve Dağlar — Google Flow kaynak kopyası

Safari’de açık Flow editörünün Kod sekmesinde listelenen 9 kaynak dosyası kopyalandı. Dosya adları, klasör yapısı ve boş kaynak satırları korundu; görüntülenen satır numaraları çıkarıldı.

Toplam 3240 satır. Tüm dosyalarda TypeScript sözdizimi ve göreli import hedefleri kontrol edildi. manifest.json dosyasında kaynak bağlantısı, kopyalama zamanı, satır sayıları ve SHA-256 özetleri bulunur.

Bu, editörde görünen kaynakların arşividir. Editörde package.json, kilit dosyası veya ayrı CSS dosyası listelenmedi. flow-sdk ve Flow ortamının sağladığı altyapı/medya bu arşive dahil değildir. Kodlar Kadra’ya entegre edilmedi ve çalıştırılmadı.

Kadra’nın TypeScript ve ESLint taramasında imports/** hariç tutuldu; Flow ortamına ait kaynaklar mevcut uygulamanın derlemesini etkilemez.
